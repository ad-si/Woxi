# `ExampleData`

`ExampleData` serves Wolfram's catalogue of example data. Its content is
generated by Woxi — drawings instead of photographs, synthesized sound,
generated text — but its structure is Wolfram's: the same collections,
entries, property names, and metadata such as sizes, counts and types. The
examples below therefore show metadata only.

`ExampleData[]` lists the collections.

```scrut
$ wo 'Length[ExampleData[]]'
19
```

```scrut
$ wo 'MemberQ[ExampleData[], "TestImage"]'
True
```

`ExampleData["collection"]` lists its entries as `{collection, name}` pairs,
ready to be passed back in.

```scrut
$ wo 'ExampleData["TestImage"][[1]]'
{TestImage, Aerial}
```

```scrut
$ wo 'Length[ExampleData["Geometry3D"]]'
27
```

`ExampleData[{"collection", "name"}, "Properties"]` lists the properties of an
entry.

```scrut
$ wo 'ExampleData[{"Text", "GettysburgAddress"}, "Properties"]'
{Author, FormattedText, FullTitle, Language, Lines, NotebookExpression, String, Title, Words}
```

## Images

```scrut
$ wo 'ImageDimensions[ExampleData[{"TestImage", "Mandrill"}]]'
{512, 512}
```

```scrut
$ wo 'ImageChannels[ExampleData[{"TestImage", "Moon"}]]'
1
```

```scrut
$ wo 'ExampleData[{"ColorTexture", "Amboyna"}, "ImageSize"]'
{302, 402}
```

## 3D models

```scrut
$ wo 'ExampleData[{"Geometry3D", "Torus"}, "PolygonCount"]'
8700
```

```scrut
$ wo 'Length[ExampleData[{"Geometry3D", "Torus"}, "VertexData"]]'
4487
```

## Audio

```scrut
$ wo 'AudioSampleRate[ExampleData[{"Audio", "Apollo11ReturnSafely"}]]'
Quantity[11025, Hertz]
```

```scrut
$ wo 'ExampleData[{"Sound", "Flute"}, "Channels"]'
1
```

## Text

```scrut
$ wo 'ExampleData[{"Text", "GettysburgAddress"}, "Author"]'
Abraham Lincoln
```

```scrut
$ wo 'Length[ExampleData[{"Text", "GettysburgAddress"}, "Lines"]]'
9
```

## Tables

```scrut
$ wo 'Dimensions[ExampleData[{"Statistics", "FisherIris"}]]'
{150, 5}
```

```scrut
$ wo 'ExampleData[{"Statistics", "FisherIris"}, "ColumnHeadings"]'
{SepalLength, SepalWidth, PetalLength, PetalWidth, Species}
```

```scrut
$ wo 'Length[ExampleData[{"MachineLearning", "FisherIris"}, "TrainingData"]]'
105
```



```scrut

```


## Messages

A name that is not in the catalogue is reported.

```scrut
$ wo 'ExampleData[{"NetworkGraph", "NoSuchNetwork"}]'

ExampleData::notent: "NoSuchNetwork" is not a known entity for the collection "NetworkGraph". Use ExampleData["NetworkGraph"] for a list of entities.
ExampleData[{NetworkGraph, NoSuchNetwork}]
```

So is a property the entry does not have.

```scrut
$ wo 'ExampleData[{"TestImage", "Moon"}, "Foo"]'

ExampleData::notpropx: "Foo" is not a known property for {"TestImage", "Moon"}. Use ExampleData[{"TestImage", "Moon"}, "Properties"] for a list of properties.
ExampleData[{TestImage, Moon}, Foo]
```

Retired entries, such as `{"TestImage", "Lena"}` and
`{"TestImage", "TestPattern"}`, are no longer listed but are still served,
with a warning.

```scrut
$ wo 'ExampleData[{"TestImage", "Lena"}, "ImageSize"]'

ExampleData::obsolete: {TestImage, Lena} is being deprecated, and may not be available in future versions of Wolfram Language.
{512, 512}
```
