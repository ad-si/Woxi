# `PermutationSupport`

Elements moved by a permutation.

```scrut
$ wo 'PermutationSupport[{1, 2, 3}]'
{}
```

```scrut
$ wo 'PermutationSupport[{2, 1}]'
{1, 2}
```

```scrut
$ wo 'PermutationSupport[{1, 3}]'

PermutationSupport::permlist: Invalid permutation list {1, 3}.
PermutationSupport[{1, 3}]
```
